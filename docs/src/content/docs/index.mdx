## What is Secret Republic V3?

**Secret Republic V3** is the feature-rich, third full version of an open source cyber security role-playing
game that runs in the browser. Players take on missions in a UNIX-like terminal, upgrade skills and
abilities, build and equip their own servers, join or found organizations, wage wars over zones of the
Grid and compete in timed "hackdown" events. There's enough here for a complete stand-alone game, and it
ships with an admin panel and a mission designer so you can run your own world.

## Run your own server in two minutes

```bash
git clone https://github.com/nenuadrian/secret-republic-browser-based-cyber-security-rpg-v3.git
cd secret-republic-browser-based-cyber-security-rpg-v3
docker compose up -d --build --wait
# open http://localhost:8080 and create the admin account
```
