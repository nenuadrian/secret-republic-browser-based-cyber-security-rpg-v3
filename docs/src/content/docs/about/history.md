Secret Republic began in **2012** as a browser game about cyber security, built from the ground up by a
then fairly inexperienced developer. V3 is its third complete rewrite and the most feature-rich version,
with enough systems to run as a stand-alone game.

## Versions

| Version | Notes |
| ------- | ----- |
| **V3** | This project: vanilla PHP, Smarty and MySQL/SQLite, with servers, organizations, the Grid, wars, forums and blogs. Modernized in 2026 for PHP 8.5, MySQL 9.7 and Docker. |
| **V4** | A newer, mobile-first rewrite on FuelPHP with far fewer features. [Docs](https://nenuadrian.github.io/secret-republic-browser-based-cyber-security-rpg-v4/) · [Code](https://github.com/nenuadrian/secret-republic-browser-based-cyber-security-rpg-v4) |
