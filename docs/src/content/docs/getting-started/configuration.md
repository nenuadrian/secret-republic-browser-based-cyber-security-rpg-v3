## Environment variables

Docker deployments read these from `.env` next to `docker-compose.yml`; `.env.example` lists them all.
Outside Docker, set them in your web server or PHP-FPM pool (`env[NAME] = value`), or with `putenv()` in
`includes/local_settings.php` (see below).

| Variable | Default | Purpose |
| -------- | ------- | ------- |
| `DB_DRIVER` | `mysql` | `mysql` or `sqlite` |
| `DB_HOST` | `db` | MySQL host. In Docker, setting it (or `DB_DRIVER=sqlite`) makes the container write `includes/database_info.php` from these variables. |
| `DB_PORT` | `3306` | MySQL port |
| `DB_NAME` / `DB_USER` / `DB_PASS` | `secretrepublic` | MySQL database and credentials. **Change the password.** |
| `DB_ROOT_PASSWORD` | `change-me-root` | MySQL root password (Compose only) |
| `SQLITE_PATH` | `includes/local.sqlite` | SQLite file, relative to the project or absolute |
| `APP_PORT` | `8080` | Host port (Compose only) |
| `CRON_KEY` | *(public default)* | Secret in [cron URLs](../cron-jobs/). **Always set it.** |
| `APP_URL` | auto-detected | Base URL for links and assets, e.g. `https://game.example.com/`. Set it behind a reverse proxy or HTTPS. |
| `APP_TIMEZONE` | `America/Detroit` | PHP timezone for the game clock |
| `SMTP_HOST` | *(empty: email off)* | SMTP server; email is disabled while empty |
| `SMTP_PORT` | `25` | SMTP port |
| `SMTP_SECURE` | *(empty)* | `''`, `tls` or `ssl` |
| `SMTP_USERNAME` / `SMTP_PASSWORD` | *(empty)* | Turn on SMTP authentication when set |
| `SMTP_FROM` | `undefined@undefined.com` | Sender address |
| `RECAPTCHA_SITE_KEY` / `RECAPTCHA_SECRET_KEY` | *(empty: off)* | Google reCAPTCHA keys |

Generate secrets with `openssl rand -hex 24`.

:::danger[Set your own CRON_KEY]
Cron URLs are protected only by `CRON_KEY`. The built-in default is visible in the public source code, so
anyone could trigger your attacks, hackdown and daily jobs until you change it.
:::

## `includes/local_settings.php`

An optional, git-ignored file loaded before the game config. Use it for machine-specific settings when you
can't change the server environment:

```php
<?php
putenv('CRON_KEY=your-long-random-secret');
putenv('SMTP_HOST=127.0.0.1');
putenv('SMTP_PORT=25');
putenv('APP_TIMEZONE=Europe/London');
```

## `includes/database_info.php`

Generated by the [setup wizard](../manual-install/#3-run-the-setup-wizard), or by the Docker entrypoint from
`docker/database_info.php`. It is git-ignored. Format (see `includes/database_info.php.template`):

```php
<?php
$db['driver'] = 'mysql';            // or 'sqlite'
$db['server_name'] = 'localhost';
$db['username'] = 'secretrepublic';
$db['password'] = 'change-me';
$db['name'] = 'secretrepublic';
$db['port'] = 3306;
$db['sqlite_path'] = 'includes/local.sqlite';

return $db;
```

## Game settings: `includes/constants/constants.php`

Game-wide settings such as the contact email, tutorial length, Grid sizes, Alpha Coin bonuses, training
and job cooldowns, and the default player group. Gameplay content (skills, abilities, tutorial steps) is
described in [Game content](../../development/game-content/).

## Email

Account confirmation, password resets, support mail and notifications are sent with PHPMailer over SMTP
once `SMTP_HOST` is set. While it is empty the game never tries to send mail.

## MySQL notes

Some game queries group by non-aggregated columns. The game turns off `ONLY_FULL_GROUP_BY` for its own
connection, so you don't need to change MySQL's global `sql_mode`.
