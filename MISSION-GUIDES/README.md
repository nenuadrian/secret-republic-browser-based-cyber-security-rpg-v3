# Missions

The PDFs in this folder are the original guides for designing and playing missions. The same material,
updated and searchable, is in the documentation:

- [Mission designer](https://nenuadrian.github.io/secret-republic-browser-based-cyber-security-rpg-v3/admin/mission-designer/): groups, objectives, hosts, services, files and Q-Syntax
- [Mission console](https://nenuadrian.github.io/secret-republic-browser-based-cyber-security-rpg-v3/game/missions/): every terminal command for SSH, SMTP and SQL

Contributions to the docs are welcome.
